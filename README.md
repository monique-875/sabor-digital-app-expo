# Sabor Digital — aplicativo

## Fazer um pedido

1. Abra **Produtos** e toque no botão **+** para colocar um item na sacola.
2. Toque em **Sacola** ou na aba **Carrinho** para conferir os itens e quantidades.
3. Informe seu nome, escolha Pix, dinheiro ou cartão e toque em **Confirmar pedido**.
4. O pagamento é feito na entrega ou retirada. O aplicativo não cobra online.

## Executar no emulador Android

1. Inicie o servidor na pasta `sabor_digital` com `npm start`.
2. Nesta pasta, execute `npm install` e `npm run android`.

O endereço padrão do servidor no emulador é `http://10.0.2.2:3000`. Em um
celular físico, abra **Servidor** no login ou no perfil e informe o endereço IP
do computador na mesma rede Wi-Fi, por exemplo `http://192.168.1.10:3000`.
